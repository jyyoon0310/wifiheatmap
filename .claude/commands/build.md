Build or run the Wi-Fi Heatmap application.

If the user said "run" or no arguments: execute `./gradlew run`
If the user said "build": execute `./gradlew build`
If the user said "clean": execute `./gradlew clean`
If the user said "jar": execute `./gradlew jar`

Use the Bash tool to execute the command from the project root.
Report the result and any errors clearly.
