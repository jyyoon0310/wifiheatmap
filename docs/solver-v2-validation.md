# Solver v2 Validation Plan

## 목적
Solver v2(2D TEz FDTD + PML)가 최소한 아래 3가지 품질 조건을 만족하는지 검증한다.

1. 경계 반사 억제(PML 안정성)
2. 재질/구조 반영(벽/문/창문 투과/차폐)
3. 런타임 안정성(step, fps, CFL)

## 공통 준비

- 평면도 로드 후 스케일 보정
- AP 1개 이상 배치
- Solver 툴 선택 후 오버레이 표시 On
- 콘솔 로그 확인:
  - `[SolverV2] dx=... dt=... CFL=... pml=... src=...`
  - `[SolverV2] runtime=... step=... fps=...`

## 시나리오 A: Empty Space

- 벽을 모두 제거
- AP 1개만 활성화
- 10초 이상 실행

### 통과 기준
- 중심에서 동심원 계열 파면이 관찰됨
- 경계선 근처에서 지속적인 강한 반사 밴드가 지배적이지 않음
- FPS가 비정상적으로 0에 수렴하지 않음

## 시나리오 B: Single Wall

- AP와 반대편 영역 사이에 직선 벽 1개
- 재질을 `CONCRETE_WALL`로 테스트 후 `DOOR`/`WINDOW`로 변경

### 통과 기준
- 콘크리트: 벽 후면 평균 세기가 뚜렷이 감소
- 문/창문: 동일 위치에서 콘크리트 대비 투과 증가
- 재질 변경 직후 패턴이 갱신됨

## 시나리오 C: Real Floorplan

- 실제 구조(복도/방/문) 유지
- AP 1~2개 배치

### 통과 기준
- 복도 방향으로 에너지 전달 경향이 보임
- 코너/벽 뒤 음영이 자연스럽게 생성
- 문/창문 구간에서 상대적 누설(투과) 관찰

## 성능/안정성 판정

- CFL 값이 `<= 1` 유지
- 실행 30초 동안 앱 프리징 없이 step 증가 지속
- 오버레이 토글은 즉시 반영(재빌드 유발 없음)
- AP/라디오 변경 시 source refresh 로그가 출력됨
