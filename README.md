# Wi-Fi Heatmap (JavaFX)

## FDTD 모드(TEz + PML) 사용법

이 프로젝트는 히트맵 생성 시 두 가지 모델을 지원합니다.

1. `Legacy(거리/벽감쇠)`  
   - 기존 로그거리 + 벽 감쇠 + 반사/회절 근사 모델
2. `FDTD(TEz+PML)`  
   - 2D TEz FDTD (Ez/Hx/Hy) + split-field PML 기반 파동 시뮬레이션
   - 간섭 줄무늬/로브/음영을 포함한 전파 패턴을 상대적으로 더 직접적으로 표현

### 실행 절차

1. 평면도 로드
2. 스케일 보정(필수)
3. AP/벽 배치
4. 상단 툴바 `모델`을 `FDTD(TEz+PML)`로 전환
5. `Solver` 탭(좌측)에서 FDTD 파라미터 설정
6. `히트맵 생성` 클릭

## FDTD 설정 항목

- `freq`: 2.4GHz / 5GHz
- `dx (m)`: 격자 간격 (권장 2.4GHz 기준 `0.01 m`)
- `steps`: 전체 타임스텝 수
- `PML cells`: 경계 PML 두께
- `Ramp(ns)`: CW source ramp-up 시간
- `Source A`: 소스 진폭(상대)
- `RMS cycles`: RMS 집계 주기 수
- `벽 프리셋`: 벽별 재질 사용 / 석고보드 / 목재 / 콘크리트
- `Reference`: AP 근처 평균 / 전역 최대 / 사용자 지정

## 권장 파라미터

- 2.4GHz
  - `dx = 0.01 m` (대략 λ/12 수준)
  - `PML = 12~16 cells`
  - `RMS cycles = 20~50`
- 5GHz
  - 해상도 유지를 위해 `dx = 0.006~0.01 m` 권장
  - 계산량 증가에 유의

## 계산량/주의사항

- FDTD는 Legacy 모델보다 계산량이 큽니다.
- 격자 수는 대략 `(가로미터/dx) x (세로미터/dx)`에 비례합니다.
- steps와 소스(AP 수)가 커지면 실행 시간이 길어집니다.
- 진행률은 Solver 상태 라벨과 로그로 출력됩니다.

## 검증 시나리오 (권장)

1. **빈 공간 + 단일 AP**
   - 벽 없이 실행
   - 원형 파면과 PML 경계 근처 반사 최소 여부 확인
2. **단일 직선 벽**
   - AP와 수신 영역 사이에 직선 벽 1개 배치
   - 반사/투과/그림자 패턴이 동시에 보이는지 확인
3. **실제 평면도**
   - 문/복도 포함 평면도에서 실행
   - 복도 방향 로브, 실내 간섭 줄무늬/음영 확인

## 재질 프리셋

- `벽별 재질 사용`: 벽 객체의 WallMaterial(문/창문 포함) 기반
- `석고보드`: 일반 벽을 석고보드로 간주
- `목재`: 일반 벽을 목재 계열로 간주
- `콘크리트`: 일반 벽을 콘크리트로 간주

문/창문은 저손실 재질로 별도 처리됩니다.
